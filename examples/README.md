# 表示の設定例

`dashboard.yaml` のセンサーを自分のエンティティに変更してください。

`scripts.json` と `morning-automations.json` の通知先・センサー・URLを変更してHAへ登録します。月〜金の8〜10時に次便を表示します（HAのタイムゾーン基準、祝日も含む）。

カウントダウンは端末側で進み、バーと位置は約2分ごと・次便への切り替わり時に更新します。バーは前便〜次便の予定間隔に対する残り時間で、走行進捗ではありません。iOSによる更新遅延があります。

あと何停留所かは乗車停留所を含む数で、次が乗車停留所なら1です。循環路線で乗車地点を特定できない場合は次の停留所名を表示します。
